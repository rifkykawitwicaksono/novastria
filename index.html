INFO SEBELUM ORDER

Pertanyaan umum

Apakah panel langsung aktif otomatis?

Belum. Pesanan diperiksa admin, pembayaran diverifikasi, lalu server dibuat manual dan akses dikirim secara pribadi.

Apakah semua bot dan game didukung?

Tidak selalu. Dukungan bergantung pada Docker image, konfigurasi server, port, dan resource yang tersedia. Konfirmasi dulu jika aplikasi khusus.

Apakah paket Unlimited benar-benar tanpa batas?

Tidak ada resource fisik yang benar-benar tanpa batas. Paket ini hanya boleh ditawarkan jika admin menjelaskan batas RAM, CPU, disk, dan kebijakan penggunaan secara jelas.

Kapan saya membayar?

Tunggu konfirmasi admin mengenai ketersediaan, harga akhir, durasi paket, dan instruksi pembayaran. Jangan membayar ke rekening yang tidak dikonfirmasi.
